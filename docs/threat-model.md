# WallPilot 威胁模型

## 保护目标

- 当前及永久防火墙配置。
- 管理员密码、TOTP密钥、会话和代理共享密钥。
- 删除对象的恢复快照。
- 防火墙变更及身份验证审计历史。
- 服务器不因误操作而失去SSH连接或意外暴露服务。

## 主要威胁

### 未授权网络访问

默认只监听回环地址，并推荐通过SSH隧道访问。随机路径减少误扫描噪声，但不被
视为身份验证。所有数据接口都要求登录，会话具有空闲和绝对过期时间。

### Web攻击

- 修改接口要求CSRF令牌，并验证Host和Origin。
- 使用严格CSP、禁止frame嵌入、禁止缓存敏感响应。
- 模板和前端使用文本转义，不把规则内容作为HTML或脚本执行。
- 登录按来源限速，错误信息不区分密码或TOTP。

### 命令注入

- 不使用 `shell=True`、`eval` 或字符串拼接的命令。
- UFW参数来自Pydantic严格模型；接口名、区域名、服务名、端口和CIDR分别验证。
- firewalld规则通过D-Bus结构化调用。
- root代理只有固定方法，systemd单元使用硬编码白名单。

### Web进程被攻破

Web进程不是root。它只能通过Unix Socket请求有限的防火墙操作，不能请求任意
systemd单元、任意文件操作或任意命令。代理同时检查Unix对端UID和HMAC。

该隔离无法防止已完全攻破的Web进程使用所有合法防火墙方法，因此默认不允许
公网直接访问，并要求系统持续更新依赖。

### 管理员误操作

所有写操作先形成草稿。删除必须经历影响提示和随机六位确认码；关闭防火墙、
删除SSH入口等高风险操作额外要求TOTP和主机名。变更在90秒内未确认时执行逆操作。

### 回收数据篡改

回收记录使用本机随机密钥计算HMAC，同时保存SQLite记录和权限为0600的JSON快照。
校验失败会阻止自动恢复，并记录安全事件。

## 明确不处理的风险

- 云安全组、边界路由器、托管负载均衡器和上游NAT。
- 已拥有服务器root权限的攻击者。
- 内核、firewalld、UFW、systemd或Python运行时本身的漏洞。
- 由另一管理工具同时写入防火墙造成的所有语义冲突。
- 原生nftables自定义链之间的完整数据包路径证明。
